Safety as set invariance

What it means for a system to be safe, why that question turns into a question about sets, and how Nagumo's theorem for an uncontrolled system becomes the control barrier function quadratic program.

Definition

The standard way to write that down is with a scalar constraint function \(h : \mathbb{R}^n \to \mathbb{R}\), continuously differentiable, chosen so that \(h\\geq 0) means the state is safe. For example:

  • Circular obstacle avoidance: \(h(x) = \|p - p_{\mathrm{obs}}\|^2 - r^2\), positive when the robot is farther than \(r\) from the obstacle centre.
  • Speed limit: \(h(x) = v_{\max}^2 - v^2\).

Usually, non-negative means safe.

Superlevel, sublevel, and level sets

Given \(h\), three sets matter:

$$\underbrace{\mathcal{C} = \{x : h(x) \ge 0\}}_{\text{0-superlevel set}}, \qquad \underbrace{\partial\mathcal{C} = \{x : h(x) = 0\}}_{\text{0-level set}}, \qquad \underbrace{\{x : h(x) \le 0\}}_{\text{0-sublevel set}}.$$

\(\mathcal{C}\) is the safe set. Its interior \(\mathrm{Int}(\mathcal{C}) = \{h \ge 0\}\) is where you are safe, and outside of the superlevel set, you are unsafe.

One technical condition recurs throughout: \(0\) should be a regular value of \(h\). That means \(\nabla h(x) \neq 0\) for every \(x \in \partial\mathcal{C}\). Geometrically, the boundary is then a genuine surface with a well-defined normal rather than a point where \(h\) touches zero tangentially.

Forward invariance and Nagumo's theorem

For an autonomous system \(\dot x = f(x)\) with \(f\) locally Lipschitz, the set \(\mathcal{C}\) is forward invariant if every trajectory starting inside stays inside:

$$x(0) \in \mathcal{C} \quad \Longrightarrow \quad x(t) \in \mathcal{C} \ \text{ for all } t \ge 0.$$

That quantifies over every trajectory and all time. Nagumo's theorem converts it into a pointwise condition.

We define thetangent cone, the set of directions pointing into \(\mathcal{C}\) or along its boundary \(\partial\mathcal{C}\):

$$T_{\mathcal{C}}(x) = \left\{ v \in \mathbb{R}^n \ :\ \liminf_{\tau \to 0^+} \frac{\mathrm{dist}(x + \tau v,\ \mathcal{C})}{\tau} = 0 \right\}.$$

Nagumo's theorem. For \(\dot x = f(x)\) with \(f\) locally Lipschitz and \(\mathcal{C}\) closed, \(\mathcal{C}\) is forward invariant if and only if

$$f(x) \in T_{\mathcal{C}}(x) \qquad \text{for all } x \in \mathcal{C}.$$

At an interior point, the tangent cone is all of \(\mathbb{R}^n\). What that means is that from strictly inside, every direction keeps you inside for at least a short time, which is trivial. What really matters is at the boundary \(\partial\mathcal{C}\).

And at the boundary, when \(0\) is a regular value of \(h\), the tangent cone is a half-space determined by the gradient,

$$T_{\mathcal{C}}(x) = \big\{ v : \nabla h(x)^\top v \ge 0 \big\}, \qquad x \in \partial\mathcal{C},$$

so the theorem collapses to one scalar inequality:

$$\dot{h}(x) = \nabla h(x)^\top f(x) \ \ge\ 0 \qquad \text{for all } x \in \partial\mathcal{C}.$$

In words: on the boundary the vector field must not point outward. It may point inward, or run exactly along the boundary.

From invariance to controlled invariance

For a control-affine system

$$\dot x = f(x) + g(x)\,u, \qquad u \in U \subset \mathbb{R}^m,$$

Controlled invariance is a property of the set. For every \(x \in \mathcal{C}\) there exists some \(u \in U\) with \(f(x) + g(x)u \in T_{\mathcal{C}}(x)\). Note it only says that a safe control input always exists for the set.

Forward invariance is a property of the closed loop. Given a specific policy \(u = \pi(x)\), every trajectory of \(\dot x = f(x) + g(x)\pi(x)\) starting in \(\mathcal{C}\) stays in \(\mathcal{C}\).

Controlled invariance is necessary for safety. If some state in \(\mathcal{C}\) admits no safe input at all, we can't ensure safety with any controller. But we also need a forward invariant controller to actually find the safe control input.

So the design problem is: given a controlled invariant set, construct a policy that renders it forward invariant. That is what a control barrier function is for.

Vector fields and Lie derivatives

The Lie derivative of a scalar function \(h\) along a vector field \(f\) is the directional derivative of \(h\) in the direction \(f\):

$$L_f h(x) \ =\ \nabla h(x)^\top f(x) \ =\ \frac{\partial h}{\partial x}(x)\, f(x).$$

It is a scalar, shows how \(f\) affects \(h\). The Lie derivative is the component of the vector field along that normal, so its sign is the in-or-out question: \(L_f h > 0\) means the flow carries you deeper into \(\mathcal{C}\), \(L_f h < 0\) means it carries you out, and \(L_f h = 0\) means it runs parallel to the level set.

Apply the chain rule to the controlled system and the rate of change of \(h\) splits cleanly in two:

$$\frac{d}{dt} h(x(t)) \ =\ \nabla h^\top \big(f(x) + g(x)u\big) \ =\ \underbrace{L_f h(x)}_{\text{drift}} \ +\ \underbrace{L_g h(x)\,u}_{\text{control}} .$$

Here \(L_g h(x) = \nabla h(x)^\top g(x)\) is a row vector in \(\mathbb{R}^{1\times m}\), one entry per input channel, each saying how strongly that channel moves \(h\). This decomposition is the whole reason control barrier functions work:

  • \(L_f h\) is what the system does to your safety margin on its own. You get no say in it.
  • \(L_g h\,u\) is your authority over that margin, and it is linear in \(u\). Any requirement of the form \(\dot h \ge \text{something}\) is therefore an affine inequality in the decision variable.
  • If \(L_g h(x) = 0\) you have no first-order authority at all: at this instant the input cannot influence \(h\), whatever you do. That is the relative-degree problem, and it is what exponential and high-order CBFs exist to handle.

From Nagumo to a condition you can enforce

Combining the last two sections, controlled invariance at a boundary point reads

$$\exists\, u \in U \ : \quad L_f h(x) + L_g h(x)\,u \ \ge\ 0, \qquad x \in \partial\mathcal{C}.$$

Correct, but awkward to build a controller around. The condition lives only on a measure-zero surface, so a controller enforcing it does nothing until the state arrives at the boundary and then must react instantaneously. Sampled at \(100\,\mathrm{Hz}\), "react instantaneously at the boundary" means "react one step after crossing it".

The fix is to extend it to a condition defined everywhere that reduces to Nagumo's at the boundary and relaxes smoothly inward. Pick an extended class \(\mathcal{K}_\infty\) function \(\alpha\) — strictly increasing, \(\alpha(0) = 0\), defined on all of \(\mathbb{R}\) so it accepts negative arguments — and require

$$\dot h(x,u) \ =\ L_f h(x) + L_g h(x)\,u \ \ge\ -\alpha\big(h(x)\big).$$

At \(h = 0\) the right-hand side is zero and this is exactly \(\dot h \ge 0\). For \(h > 0\) it is negative, so \(h\) is allowed to decrease, and the deeper inside you are the faster it may decrease. The constraint interferes only as the margin runs out.

The proof that this suffices is a comparison argument rather than a tangent-cone one. If the inequality holds along a trajectory, then \(h(x(t))\) is bounded below by the solution of the scalar ODE \(\dot y = -\alpha(y)\) with \(y(0) = h(x(0)) \ge 0\); since \(y = 0\) is an equilibrium of that ODE, \(y(t) \ge 0\) for all \(t\), and therefore \(h(x(t)) \ge 0\).

Note what that argument needs: the inequality must hold along the whole trajectory, not merely at points of \(\mathcal{C}\). That is why the CBF condition is stated on a domain \(D \supset \mathcal{C}\) rather than on \(\mathcal{C}\) alone, and it is where the regular-value condition from section 2 comes back. The next page takes that apart.

Two flavours: reciprocal and zeroing

Historically there are two ways to build a barrier from a constraint function, and the literature from roughly 2014 to 2017 carries both.

Reciprocal CBFs

A reciprocal barrier function \(B\) is built to blow up at the boundary,

$$B(x) \to \infty \ \text{ as } \ x \to \partial\mathcal{C}, \qquad \text{typically} \quad B = \frac{1}{h} \quad \text{or} \quad B = -\log\!\frac{h}{1+h},$$

and is then required to stay bounded along trajectories, which keeps the state strictly inside. It is a literal barrier: an infinite wall at the edge of the set.

The drawbacks are what retired it. \(B\) is defined only on \(\mathrm{Int}(\mathcal{C})\), so it certifies invariance of the open interior and says nothing once you touch the boundary. It is numerically ill-conditioned near the edge. And it is fragile in the way that matters most: if a disturbance or model error pushes the state onto or past the boundary, \(B\) is undefined and there is no recovery condition to appeal to. Keeping a reciprocal barrier finite as the state approaches the boundary generally demands unbounded control effort.

Zeroing CBFs

A zeroing barrier function is \(h\) itself, which goes to zero at the boundary rather than to infinity, with the condition \(\dot h \ge -\alpha(h)\) from the previous section. Being finite everywhere, it is defined on both sides of the boundary, and that is exactly what buys robustness: outside the set \(h < 0\), so \(-\alpha(h) > 0\) and the condition demands that \(h\) increase. It drives the state back. The set is not merely invariant but asymptotically stable.

In current usage "control barrier function" means the zeroing kind, and the reciprocal form survives mainly as a historical note. Worth recognising when reading older papers, not worth implementing.

The intuition worth keeping

A zeroing CBF does not keep you away from the boundary. It lets you go right up to it, and only insists that when you get there, you still have the authority to stay in.

That is the shift from the reciprocal picture, and it is why CBFs are usable as a filter around an existing controller. The constraint \(\dot h \ge -\alpha(h)\) is slack while \(h\) is large: deep inside the set the margin may be spent freely and the nominal controller runs untouched. As \(h\) shrinks the permitted rate of decrease shrinks with it, so the margin is spent more and more slowly — you decelerate toward the boundary rather than being repelled from it. At \(h = 0\) the permitted rate is exactly zero, which is Nagumo's condition, and at that moment the input has to be able to deliver \(\dot h \ge 0\).

"Able to deliver" is the real content. It is the requirement that

$$K_{\mathrm{cbf}}(x) = \big\{ u \in U : L_f h(x) + L_g h(x)\,u + \alpha(h(x)) \ge 0 \big\}$$

be nonempty at every state — which at a boundary point needs \(L_g h(x) \neq 0\), so that the input has first-order authority over \(h\), and needs \(U\) to be large enough to overcome the drift \(L_f h(x)\). A CBF is a certificate that this authority is present everywhere, not that the boundary is far away.

Scaling \(\alpha\) up makes the constraint more permissive, letting the state approach faster and brake later; scaling it down keeps the state conservatively inside. This is the main tuning knob, and under input bounds it is not a free one: brake too late and the input required at the boundary exceeds what the actuators can supply.

The CBF-QP

Now assemble. You have a nominal controller \(k(x)\) that does whatever the task requires and knows nothing about safety, and a constraint that is affine in \(u\). So ask for the smallest modification to the nominal input that satisfies the constraint:

$$\begin{aligned} u^\star(x) \ =\ \underset{u \in U}{\arg\min} \quad & \tfrac{1}{2}\big\|u - k(x)\big\|^2 \\ \text{subject to} \quad & L_f h(x) + L_g h(x)\,u \ \ge\ -\alpha\big(h(x)\big). \end{aligned}$$

A quadratic objective with affine constraints: a quadratic program, solvable in microseconds, which is why this runs at control rate. Several safety constraints are several rows. A control Lyapunov function for the task can be added as another row, usually with a slack variable so that safety takes precedence over stability.

The structure is modular in a way that matters in practice. The nominal controller can be a PID loop, an MPC, or a learned policy; the filter does not care, and it intervenes only when the constraint is about to bind. This is the safety filter pattern.

Three things are easy to assume here and none is free: that \(K_{\mathrm{cbf}}(x)\) stays nonempty once \(U\) is bounded, that \(u^\star(x)\) depends continuously on \(x\), and that imposing the CBF condition on \(\mathcal{C}\) is the same as imposing it on \(D\). Each fails in identifiable circumstances.

Where this goes

The construction above is standard and sound, but every step carries a hypothesis: the regular-value condition on \(h\), the choice of \(D\) over \(\mathcal{C}\), the Lipschitz continuity of the controller the QP produces. Those are the places where the guarantee can quietly stop holding, and the next page works through the three I found most confusing.
